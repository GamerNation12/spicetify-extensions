# Hide Podcasts & Audiobooks

A Spicetify extension that hides the "Podcasts & Shows" and "Audiobooks" buttons from the Home page filters and the Sidebar library filters.

## Installation

1. Copy the `HidePodcasts.js` file into your Spicetify `Extensions` folder.
2. Run `spicetify config extensions HidePodcasts.js`.
3. Run `spicetify apply`.
