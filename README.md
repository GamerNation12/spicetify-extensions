# spicetify-extensions

The spicetify extensions that I have made.

### 📦 Included Extensions

*   **[Beautiful Release Date](./beautiful-release-date/README.md)** — A heavily upgraded extension that displays the exact release date, age, and live **Track Popularity** (🔥) of your currently playing music. Features highly customizable placement options, including a sleek frosted **Floating Pill** above your track info!
*   **[Diagnostics & Accent Customizer (Test Plugin)](file:///c:/Users/minec/Documents/GitHub/spicetify-extensions/test-plugin/README.md)** — A sandbox utility showing live track telemetry, checking Spicetify API health, exposing controls, adding pulsing RGB player underglows, and toggleable natively in the user profile settings menu.
